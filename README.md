# XCPC Template

个人 XCPC 算法模板库，使用 C++17，收录数据结构、图论、数学、字符串、计算几何等常用算法，以及比赛入口和对拍工具。HTML 版支持搜索与代码复制，另提供 PDF 模板册和 OEIS 检索附册，方便比赛时查阅、打印。
