# XCPC Template

我自己比赛和练习时用的 C++17 算法模板，按数据结构、图论、数学、字符串、计算几何等分类整理。

[在线阅读与 PDF](https://chzhc.cn/xcpc/)

## 内容

- **算法片段**：按需复制到比赛代码里，使用条件、复杂度和容易踩的坑写在代码旁。
- **网页查阅**：搜索目录定位算法，一键复制代码，手机上也能翻。
- **打印册**：提供带目录的 PDF，方便赛前打印和场上查阅。
- **OEIS 附册**：查找常见数列，和模板册放在同一个阅读入口。
- **比赛工具**：附比赛代码入口和对拍工具。

代码在 [template/](template/)，接口索引见[模板说明](support/PROJECT.md)，对拍用法见[对拍工具](support/tools/stress/README.md)。
