# XCPC Template

这是一个面向 XCPC 竞赛的 C++17 算法模板库。每个模板均以仓库中的 `.cpp` 文件为唯一代码来源，可以直接复制到比赛代码中。

## 浏览模板

- [模板索引](algorithms/index.md)：按数据结构、图论、数学等分类浏览全部模板。
- [使用说明](guide.md)：本地预览、严格构建和 GitHub Pages 部署方法。

## 项目约定

- 算法模板默认不包含 `int main()`。
- 图和树通常使用 1-based 顶点编号，例外会在模板说明中注明。
- 模板页由 `tools/generate_docs.py` 从 `.cpp` 文件生成，不手工维护第二份代码。
- 重要算法除编译检查外，还应通过样例、随机测试或对拍验证。
