# 对拍工具

`tools/stress/` 提供一套最小可运行的对拍示例，用于比较暴力程序和标准程序在随机数据上的输出。

## 文件说明

- `generator.cpp`：接收随机种子，每次生成一组测试数据；
- `brute.cpp`：示例的 `O(n^2)` 暴力程序；
- `standard.cpp`：示例的 `O(n)` 标准程序；
- `run.py`：编译上述程序，循环生成数据并按空白分隔的 token 比较输出。

当前示例计算非空整数序列的最大子段和。工具程序可以保留 `int main()`，但不要把入口复制到算法模板中。

## 运行方式

在仓库根目录执行：

```powershell
python tools/stress/run.py --tests 1000 --seed 1
```

脚本使用 `g++ -std=c++17 -O2 -Wall -Wextra -pedantic` 编译程序。需要使用其他编译器时，传入 `--compiler`。

若发现差异，脚本会输出测试轮数和随机种子，并将输入、暴力输出和标准输出保存到 `build/stress/`。该目录是本地构建产物，不提交到 Git。

## 改成题目对拍

1. 修改 `generator.cpp`，使其生成题目输入，并保留命令行随机种子；
2. 将 `brute.cpp` 替换为只保证小数据正确的暴力解法；
3. 将 `standard.cpp` 替换为需要验证的算法；
4. 先减少数据范围确认流程正常，再逐步扩大范围和测试轮数。

三个程序必须使用完全相同的输入输出协议。答案只写到标准输出；调试信息写到标准错误，避免参与比较。当前脚本不包含 special judge，自定义判定题需要按题意修改比较逻辑。
